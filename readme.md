# Finzarc Assignment - Backend Part

## Overview

Backend for the Task Manager App, built for the Finzarc full-stack developer assignment. Handles user authentication and task CRUD operations with a secure API.

**Deployed API**: [https://finzarc.rahulgupta.tech/api](https://finzarc.rahulgupta.tech/api)

## Features

- Secure user login/signup with JWT and bcrypt.
- Task creation, update, completion, and deletion.
- RESTful API with error handling.
- Data validation for reliable inputs.

## Tech Stack

- **Node.js**: Server-side runtime.
- **Express**: Fast, minimal web framework.
- **MongoDB**: NoSQL database for task and user storage.
- **JWT**: JSON Web Tokens for authentication.
- **Bcrypt**: Password hashing for security.
- **AWS**: Deployment platform with EC2/S3 for scalability.

## Future Scope

- Implement task pagination.
- Enhance API rate limiting.
- Add user roles for admin access.
